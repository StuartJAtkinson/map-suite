## Integration Roadmap

> **Aim:** Pull in functionality from the projects listed below, take inspiration
> from open-source and commercial alternatives, analyse their features and integrate
> the best ideas into this software.
>
> **Long-term goal:** 2-way sync compatibility with the open-source and commercial
> alternatives listed here, so data and workflows move freely in both directions.

### My projects to absorb

| Project | What it contributes |
|---------|---------------------|
| [qgis-mcp](https://github.com/StuartJAtkinson/qgis-mcp) | Connects QGIS desktop to Claude AI via Model Context Protocol for AI-assisted GIS analysis |
| [Fantasy-Map-Generator](https://github.com/StuartJAtkinson/Fantasy-Map-Generator) | Web app generating interactive, highly customisable fantasy maps procedurally |
| [planetiler](https://github.com/StuartJAtkinson/planetiler) | Planet-scale vector tileset generator from OpenStreetMap data (fork) |
| [OSM2World](https://github.com/StuartJAtkinson/OSM2World) | Convert OpenStreetMap data into 3D world models (fork) |
| [streets-gl](https://github.com/StuartJAtkinson/streets-gl) | WebGL2-powered 3D OpenStreetMap renderer (fork) |
| [openindoor6](https://github.com/StuartJAtkinson/openindoor6) | Indoor mapping and routing web app using OpenStreetMap indoor data |
| [OsmGo](https://github.com/StuartJAtkinson/OsmGo) | Progressive web app for mobile OpenStreetMap editing in the field (fork) |
| [worldengine](https://github.com/StuartJAtkinson/worldengine) | Procedural world generator simulating plates, rain shadow and erosion (fork) |
